Ever felt like your money disappears faster than your snacks during a Netflix binge? 😩  
Worry not. **Expense Tracker** is here to rescue your budget and slap some sense into your spending habits. 📊⚔️

---

## 🚀 What is this?

A sleek, Python-powered **Discord bot** that helps you track your income, expenses, and financial habits — right inside your server.

---

## 🧩 Features

- ➕ Add, delete, and view transactions  
- 🗂️ Categorize expenses and incomes  
- 📊 Generate monthly summaries  
- 💾 Persistent data storage using Google Sheets 
- 💬 Clean, Discord-based command interface

## 🧠 How to Use

### 1. Clone the repo
```bash
git clone https://github.com/IshanPaharia/Expense-Tracker.git
cd Expense-Tracker
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure the .env file

Put the required credentials in the .env file

### 4. Run the bot
```bash
python bot.py
```

### 5. Invite to Discord & Start Tracking

Use the bot in any server it’s invited to and start tracking with commands like:

```diff
!add expense Food 500
!summary
!exhelp
```
